================================================================================
ENHANCEMENTS:
================================================================================

1. Stock Analysis:
   - Cross-validates prices between Yahoo Finance and Alpha Vantage
   - Displays price discrepancy percentage
   - Shows data consistency rating (High/Medium/Low)
   - Includes RSI value and signal (Oversold/Neutral/Overbought)

2. Recommendations:
   - Base recommendation from Yahoo Finance technicals
   - RSI-adjusted recommendation from Alpha Vantage
   - Final consensus recommendation combining both sources
   - Example: "Buy" + "Oversold RSI" = "Strong Buy"

3. Scoring System (60 points):
   - Recommendation quality: 10 pts
   - Risk level: 10 pts
   - Day momentum: 5 pts
   - Volume ratio: 5 pts
   - News sentiment: 10 pts
   - Trajectory prediction: 10 pts
   - RSI indicator: 10 pts (NEW)

4. Reports:
   - Shows RSI with emoji indicators (📉 📈 ➡️)
   - Displays data validation status (✓ ⚠ ❌)
   - Includes Alpha Vantage insights
   - Enhanced disclaimers with data sources

================================================================================
USAGE:
================================================================================

SETUP:
1. Get free Alpha Vantage API key:
   https://www.alphavantage.co/support/#api-key

2. Set environment variable:
   export ALPHA_VANTAGE_API_KEY="your_key_here"

3. Install requests:
   pip install requests

CLI USAGE:
# Analysis with Alpha Vantage (default enabled)
python feature_manager.py analyze --list penny --top 20

# All features automatically use Alpha Vantage:
- Stock analysis
- Top N recommendations
- Historical analysis (if needed)

MCP USAGE:
# Multi-source comparison
await get_multi_source_stock_data("AAPL")

# Enhanced recommendation
await get_comprehensive_recommendation("TSLA", use_alpha_vantage=True)

# Detailed comparison
await compare_stock_sources("NVDA")
